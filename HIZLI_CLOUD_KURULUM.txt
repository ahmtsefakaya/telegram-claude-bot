  ADIM 2: Render Hesabı
  ────────────────────────────────────────────────────────────────────
  
  1. https://render.com/ → "Get Started"
  2. GitHub ile giriş yap


  ADIM 3: Web Service Oluştur
  ────────────────────────────────────────────────────────────────────
  
  1. "New +" → "Web Service"
  2. GitHub repository bağla
  3. Repository seç: "telegram-claude-bot"
  
  Yapılandırma:
    Name: telegram-claude-bot
    Runtime: Python 3
    Build Command: pip install -r requirements.txt
    Start Command: uvicorn server:app --host 0.0.0.0 --port $PORT
    Plan: Free


  ADIM 4: Environment Variables
  ────────────────────────────────────────────────────────────────────
  
  "Environment" sekmesi → Ekle (Railway ile aynı)


  ADIM 5: Deploy
  ────────────────────────────────────────────────────────────────────
  
  "Create Web Service" → Deployment başlar!
  
  ⚠️ NOT: 15 dakika inaktivite sonrası uyur.
  İlk mesaj 30-60 saniye sürebilir.
