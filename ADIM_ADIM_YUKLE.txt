ADIM 2: Railway'de Eski Projeyi Sil
────────────────────────────────────────────────────────────────────
1. https://railway.app/dashboard
2. Mevcut projeye tıkla
3. Settings sekmesi
4. En alta kaydır
5. "Delete Service" tıkla
6. Proje adını yaz ve onayla


ADIM 3: Railway'de Yeni Proje Oluştur
────────────────────────────────────────────────────────────────────
1. Railway dashboard
2. "New Project" tıkla
3. "Deploy from GitHub repo" seç
4. Repository seç: telegram-claude-bot
5. "Deploy Now" tıkla


ADIM 4: Deployment'ı İzle
────────────────────────────────────────────────────────────────────
1. "Deployments" sekmesine git
2. En son deployment'a tıkla
3. "View Logs" tıkla

Şunları göreceksin:
✅ "Detected Python"
✅ "Found Procfile"
✅ "Installing dependencies..."
✅ "Starting with: uvicorn server:app..."
✅ "Uvicorn running on http://0.0.0.0:XXXX"


ADIM 5: Environment Variables Ekle
────────────────────────────────────────────────────────────────────
1. "Variables" sekmesine git
2. RAILWAY_ENV_VARIABLES.txt dosyasını aç
3. 15 değişkeni kopyala-yapıştır


ADIM 6: Test Et
────────────────────────────────────────────────────────────────────
1. Settings → Domains → URL'i kopyala
2. Tarayıcıda aç: [URL]/health
3. Şunu gör: {"status": "healthy"}
4. Telegram'dan /start gönder
5. Bir soru sor
