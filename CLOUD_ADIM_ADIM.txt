  ☐ ADIM 1: GitHub Hesabı
  ────────────────────────────────────────────────────────────────────
  
  Eğer GitHub hesabın yoksa:
  1. https://github.com/signup adresine git
  2. Email, kullanıcı adı, şifre belirle
  3. Email'ini doğrula
  
  ✅ GitHub hesabım var


  ☐ ADIM 2: Git Kurulumu Kontrol
  ────────────────────────────────────────────────────────────────────
  
  Komut satırında çalıştır:
  
    git --version
  
  Eğer "git is not recognized" hatası alırsan:
  1. https://git-scm.com/download/win adresine git
  2. Git'i indir ve kur
  3. Bilgisayarı yeniden başlat
  
  ✅ Git kurulu


  ☐ ADIM 3: Git Yapılandırması
  ────────────────────────────────────────────────────────────────────
  
  Komut satırında çalıştır:
  
    git config --global user.name "Adın Soyadın"
    git config --global user.email "github@email.com"
  
  ✅ Git yapılandırıldı

  📤 GITHUB'A YÜKLEME (5 DAKİKA)

  ☐ ADIM 4: GitHub Repository Oluştur
  ────────────────────────────────────────────────────────────────────
  
  1. https://github.com/new adresine git
  2. Repository name: telegram-claude-bot
  3. Description: Free Claude Code Telegram Bot
  4. Public seç (ücretsiz deployment için gerekli)
  5. "Create repository" tıkla
  
  ✅ Repository oluşturuldu


  ☐ ADIM 5: Kodu GitHub'a Yükle
  ────────────────────────────────────────────────────────────────────
  
  Komut satırını aç ve çalıştır:
  
    cd c:\Users\ahmet\OneDrive\Desktop\freeclaude\free-claude-code
    
    git init
    git add .
    git commit -m "Initial commit for cloud deployment"
    
    git remote add origin https://github.com/KULLANICI_ADIN/telegram-claude-bot.git
    git branch -M main
    git push -u origin main
  
  NOT: KULLANICI_ADIN yerine kendi GitHub kullanıcı adını yaz!
  
  İlk push'ta GitHub kullanıcı adı ve şifre/token isteyecek.
  
  ✅ Kod GitHub'a yüklendi

  🚂 RAILWAY DEPLOYMENT (5 DAKİKA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ☐ ADIM 6: Railway Hesabı Oluştur
  ────────────────────────────────────────────────────────────────────
  
  1. https://railway.app/ adresine git
  2. "Start a New Project" tıkla
  3. "Login with GitHub" seç
  4. GitHub ile giriş yap
  5. Railway'e GitHub erişimi ver
  
  ✅ Railway hesabı oluşturuldu


  ☐ ADIM 7: Projeyi Deploy Et
  ────────────────────────────────────────────────────────────────────
  
  1. Railway dashboard'da "New Project" tıkla
  2. "Deploy from GitHub repo" seç
  3. Repository'ni bul: "telegram-claude-bot"
  4. Repository'ye tıkla
  5. "Deploy Now" tıkla
  
  Railway otomatik olarak:
  • Kodu çeker
  • Bağımlılıkları kurar
  • Uygulamayı başlatır
  
  Bu 2-3 dakika sürebilir. Bekle...
  
  ✅ Deployment başladı


  ☐ ADIM 8: Environment Variables Ekle
  ────────────────────────────────────────────────────────────────────
  
  1. Railway dashboard'da projeye tıkla
  2. "Variables" sekmesine git
  3. "New Variable" tıkla
  4. Aşağıdaki değişkenleri TEK TEK ekle:
  
  ┌──────────────────────────────────────────────────────────────────┐
  │ Variable Name              │ Value                               │
  ├──────────────────────────────────────────────────────────────────┤
  │ MESSAGING_PLATFORM         │ telegram                            │
  │ TELEGRAM_BOT_TOKEN         │ 8945990527:AAGDi5yqWo75vNVMv1n0... │
  │ ALLOWED_TELEGRAM_USER_ID   │ 7701576435                          │
  │ NVIDIA_NIM_API_KEY         │ nvapi-DG4hh57MQZL9Z6LevgQXwL5q... │
  │ MODEL                      │ nvidia_nim/z-ai/glm-5.1             │
  │ ANTHROPIC_AUTH_TOKEN       │ freecc                              │
  │ FCC_OPEN_BROWSER           │ false                               │
  │ HOST                       │ 0.0.0.0                             │
  │ PORT                       │ 8080                                │
  └──────────────────────────────────────────────────────────────────┘
  
  5. Her değişkeni ekledikten sonra "Add" tıkla
  
  ✅ Environment variables eklendi


  ☐ ADIM 9: Deployment'ı İzle
  ────────────────────────────────────────────────────────────────────
  
  1. "Deployments" sekmesine git
  2. En son deployment'a tıkla
  3. "View Logs" tıkla
  
  Logları izle. Şunları göreceksin:
  • "Installing dependencies..."
  • "Starting application..."
  • "Application startup complete"
  • "Uvicorn running on..."
  
  ✅ Deployment başarılı

  ☐ ADIM 10: Health Check
  ────────────────────────────────────────────────────────────────────
  
  1. Railway dashboard'da "Settings" sekmesine git
  2. "Domains" bölümünde URL'i kopyala
     Örnek: https://telegram-claude-bot-production.up.railway.app
  
  3. Tarayıcıda aç: [URL]/health
     Örnek: https://telegram-claude-bot-production.up.railway.app/health
  
  4. Şunu görmelisin:
     {"status": "healthy"}
  
  ✅ Health check başarılı


  ☐ ADIM 11: Telegram'dan Test
  ────────────────────────────────────────────────────────────────────
  
  1. Telegram'ı aç
  2. Botunu bul
  3. /start gönder
  4. Bir soru sor:
     "Merhaba, sen kimsin?"
  
  5. Bot 5-10 saniye içinde yanıt vermeli
  
  ✅ Telegram testi başarılı
