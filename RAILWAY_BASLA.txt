ADIM 1: GitHub Hesabı Oluştur
→ https://github.com/signup

ADIM 2: Railway Hesabı Oluştur
→ https://railway.app/
→ GitHub ile giriş yap

ADIM 3: GitHub Repository Oluştur
→ https://github.com/new
→ Repository name: telegram-claude-bot
→ Public seç

ADIM 4: Kodu GitHub'a Yükle
→ RAILWAY_GITHUB_YUKLE.bat çift tıkla
→ Talimatları takip et

ADIM 5: Railway'de Deploy Et
→ https://railway.app/dashboard
→ "New Project" → "Deploy from GitHub repo"
→ Repository seç: telegram-claude-bot

ADIM 6: Environment Variables Ekle
→ Railway Dashboard → Variables
→ RAILWAY_ENV_VARIABLES.txt dosyasını aç
→ 15 değişkeni kopyala-yapıştır

ADIM 7: Test Et
→ Health check: [URL]/health
→ Telegram'dan /start gönder
