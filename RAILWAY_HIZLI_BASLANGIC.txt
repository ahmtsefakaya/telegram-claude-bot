□ ADIM 1: GitHub Hesabı
  → https://github.com/signup
  → Email, kullanıcı adı, şifre belirle
  → Email'ini doğrula

□ ADIM 2: Railway Hesabı
  → https://railway.app/
  → "Start a New Project" tıkla
  → GitHub ile giriş yap


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📤 GITHUB'A YÜKLEME (5 DAKİKA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ ADIM 3: GitHub Repository Oluştur
  → https://github.com/new
  → Repository name: telegram-claude-bot
  → Public seç
  → "Create repository" tıkla

□ ADIM 4: Kodu Yükle
  → RAILWAY_GITHUB_YUKLE.bat dosyasına çift tıkla
  → Talimatları takip et
  → GitHub kullanıcı adını gir
  → Push tamamlanana kadar bekle


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  🚂 RAILWAY DEPLOYMENT (3 DAKİKA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ ADIM 5: Railway'de Deploy Et
  → https://railway.app/dashboard
  → "New Project" tıkla
  → "Deploy from GitHub repo" seç
  → Repository seç: telegram-claude-bot
  → "Deploy Now" tıkla
  → 2-3 dakika bekle (build tamamlanana kadar)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ⚙️ ENVIRONMENT VARIABLES (5 DAKİKA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ ADIM 6: Variables Ekle
  → Railway dashboard → Projeye tıkla
  → "Variables" sekmesine git
  → "New Variable" tıkla
  
  → RAILWAY_ENV_VARIABLES.txt dosyasını aç
  → Her değişkeni TEK TEK kopyala-yapıştır
  → Toplam 15 değişken ekle
  
  → Railway otomatik yeniden deploy eder
  → "Deployments" sekmesinden izle


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ ADIM 7: Health Check
  → Railway dashboard → "Settings" sekmesi
  → "Domains" bölümünde URL'i kopyala
  → Tarayıcıda aç: [URL]/health
  → Şunu gör: {"status": "healthy"}

□ ADIM 8: Telegram Test
  → Telegram'ı aç
  → Botunu bul
  → /start gönder
  → Bir soru sor: "Merhaba, sen kimsin?"
  → Bot 5-10 saniye içinde yanıt vermeli
